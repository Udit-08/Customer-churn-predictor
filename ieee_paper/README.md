# IEEE Overleaf Paper

This folder contains an IEEE conference-format paper source describing the customer churn Streamlit project.

## Use in Overleaf

1. Create a new blank project in Overleaf.
2. Upload `main.tex` from this folder.
3. Set `main.tex` as the main document if Overleaf does not select it automatically.
4. Replace the author, institution, and email placeholders near the top of the file.
5. Compile with pdfLaTeX.

The references are included directly in `main.tex`, so no separate bibliography file is needed. The paper's metrics were recomputed from the project workbook with the app's current modeling pipeline. Recompute them if the workbook or model settings change. Confirm all reported results, dataset attribution, and institutional requirements before submitting this as a research paper.
